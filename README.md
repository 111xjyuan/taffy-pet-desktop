# 永雏塔菲 · 桌面宠物（独立版）

一个**不依赖 DSH**、没有计费功能的纯桌面宠物：全屏透明窗口 + 3D 塔菲（VRM）+ 真动捕动画 + 随机语音 + 经典表情。

> 这是 [`dsh-taffy-pet`](https://github.com/111xjyuan/dsh-taffy-pet) 的独立版本：把「DSH 右侧挂件」拆出来做成一个能单独运行的桌面程序。

## 功能

- **3D 塔菲**：three.js + three-vrm 渲染官方 Q 版 VRM，含呼吸、眨眼、视线跟随、待机微动作
- **真动捕动画**：`.vrma`（VRM Animation）驱动，动作之间 crossFade，点一下就演一段
- **经典表情**：开心 / 爱心眼 / 微笑 / 脸红 / 泪眼 / 生气 / 难过 / 惊讶 / 得意 / 害羞 / 无语 / 委屈 / 兴奋 / 困困（随机表情 3~10 分钟才来一次，不会一直演）
- **随机语音**：按压随机播放，右键菜单里可调音量、关音效
- **桌面级交互**：鼠标穿透（只有压在塔菲身上才响应）、拖动、贴边吸附、右键菜单
- **没有计费**：和 DSH 的余额/消耗彻底无关

## 运行

```bash
npm install          # 只会装 electron
npm run seed         # 从 DSH 版目录复制素材（可选，见下）
npm start
```

首次运行会把 `assets/` 里的素材复制到用户目录（`%APPDATA%/taffy-pet-desktop/assets`），之后你可以直接改那里的文件。

## 素材

`assets/` 目录里放三类东西（结构固定）：

```
assets/
  art/            2D 立绘（outfits/、small/、manifest.json）
  audio/          语音（*.wav + audio.json）
  vrm/            *.vrm 模型，vrm/anim/*.vrma 动作
```

**换成你自己的模型**：把任意 `.vrm` 丢进 `%APPDATA%/taffy-pet-desktop/assets/vrm/`，重启后右键 → 换装 → 3D 模型里就能选。
**加动作**：把 `.vrma` 丢进 `vrm/anim/`，右键 → 动作里出现。

## 交互

| 操作 | 效果 |
|---|---|
| 左键点一下 | 随机语音 + 表情 + 气泡 + 随机一段动作 |
| 按住头顶 | 摸头（轻晃 + 专属语音） |
| 右键 | 设置菜单（换装 / 动作 / 表情 / 声音 / 设置） |
| 拖动 | 抱着走，松手自动贴底边 |
| 托盘菜单 | 置顶开关、打开素材目录、退出 |
